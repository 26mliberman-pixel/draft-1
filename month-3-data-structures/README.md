## Key Concepts

- **Lists**: Ordered collections `[1, 2, 3]` — add, remove, sort, search
- **Tuples**: Like lists but can't be changed `(1, 2, 3)` — used for fixed data
- **Dictionaries**: Key-value pairs `{"name": "Alice", "age": 25}` — look up data fast
- **Sets**: Unique items only `{1, 2, 3}` — no duplicates
- **File I/O**: Reading from and writing to files on your computer
- **CSV**: Comma-Separated Values — a common data format
- **JSON**: A data format used everywhere on the internet
