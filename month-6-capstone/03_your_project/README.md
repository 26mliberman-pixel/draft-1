# Capstone 3: YOUR Project

This is YOUR time. Build something YOU want to build.

## The Rules

1. It must use at least 3 skills from different months
2. It must have a user interface (CLI or web)
3. It must store data (file or database)
4. It must have at least 5 features

## Project Ideas

Pick one that excites YOU, or come up with your own:

### Beginner-Friendly
- **Recipe Manager** — Store recipes, search by ingredient, generate shopping lists
- **Workout Logger** — Log exercises, track progress, show personal records
- **Movie/Book Tracker** — Rate, review, and track what you've watched/read
- **Flashcard App** — Create decks, quiz yourself, spaced repetition

### Intermediate
- **Personal Wiki** — A note-taking app with links between pages (like Wikipedia)
- **Budget Planner** — Set budgets, track spending, project future savings
- **Job Application Tracker** — Track applications, interviews, follow-ups
- **Social Media Dashboard** — Pull data from APIs, display in one place

### Ambitious
- **Multiplayer Game** — Tic-tac-toe or trivia over the network
- **Data Dashboard** — Visualize real data (weather trends, stock prices, etc.)
- **Automation Suite** — File organizer + email sender + web scraper combined
- **Mini E-Commerce** — Product catalog, cart, checkout (no real payments)

## Steps to Build It

1. **Pick your idea** — What excites you?
2. **List the features** — What will it do? Keep it simple at first.
3. **Design the data** — What data do you need to store? What's the structure?
4. **Build the MVP** — Minimum Viable Product. Get the core feature working first.
5. **Add features one at a time** — Don't try to build everything at once.
6. **Test it** — Break it on purpose. Fix the bugs.
7. **Polish it** — Make it look nice. Handle edge cases.
8. **Show it off!** — Put it on GitHub. Add it to your portfolio.
