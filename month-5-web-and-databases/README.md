# Month 5: Web Development & Databases

You're building REAL web applications now. This is where it gets exciting —
you'll create apps other people can use in their browser.

## Setup

Install Flask (a simple web framework) and other dependencies:

```bash
pip install flask
```

## Key Concepts

- **Flask**: A Python web framework (lets you build websites with Python)
- **Routes**: URLs that map to Python functions
- **Templates**: HTML files with dynamic content
- **SQLite**: A simple database that stores data in a single file
- **SQL**: The language used to talk to databases
- **HTML**: The structure of web pages
- **CSS**: The styling of web pages
- **REST API**: A standard way to build APIs
- **CRUD**: Create, Read, Update, Delete — the four basic operations
