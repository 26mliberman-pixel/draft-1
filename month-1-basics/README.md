# Month 1: The Absolute Basics

This is where everyone starts. No shame. The best programmers in the world once typed
their first `print("Hello")` just like you're about to.

## What is programming?

You're writing instructions for a computer. That's it. The computer is incredibly fast
but incredibly stupid — it does EXACTLY what you tell it, nothing more, nothing less.

Python is just one of many languages you can use to write these instructions.

## How long should this take?

About 1–2 hours per project. Do one project per day if you can.
Some days you'll fly through them. Some days you'll be stuck. Both are normal.

## Key Concepts This Month

- **print()** — shows text on the screen
- **variables** — named containers that store values
- **input()** — asks the user to type something
- **data types** — strings (text), integers (whole numbers), floats (decimals)
- **type conversion** — turning one type into another (e.g., `int("5")` turns the text "5" into the number 5)
- **f-strings** — a way to mix variables into text: `f"Hello {name}"`
