## Key Concepts

- **Class**: A blueprint for creating objects (like a cookie cutter)
- **Object**: A specific instance of a class (like a cookie)
- **__init__**: The special method that runs when you create an object
- **self**: How an object refers to itself
- **Inheritance**: Building new classes from existing ones
- **API**: Application Programming Interface — how programs talk to each other
- **HTTP**: How the internet sends data
- **pip**: Python's package manager — install other people's code

## Setting Up for APIs

For the API projects, you'll need to install the `requests` library:

```bash
pip install requests
```

If that doesn't work, try: `pip3 install requests`
