# Python Learning Path: Zero to Proficient in 6 Months

Welcome! This is your complete roadmap to learn Python programming from absolute scratch.

## What You Need Before Starting

1. **A computer** (Windows, Mac, or Linux — any will work)
2. **Install Python**: Go to https://www.python.org/downloads/ and download the latest version. Click "Install" and **CHECK THE BOX** that says "Add Python to PATH" — this is important!
3. **A text editor**: Download VS Code from https://code.visualstudio.com/ — it's free and the most popular editor.

## How This Course Is Organized

```
month-1-basics/          ← You are here. Start from project 01.

month-6-capstone/        ← Put it all together with real projects
```

## The Rules

1. **Type every single line of code yourself.** Do NOT copy-paste. Your fingers need to learn.
2. **Run your code after every change.** See what happens. Break things on purpose.
3. **Read the error messages.** They tell you exactly what's wrong and where. This is a skill.
4. **Do every project in order.** Each one builds on the last.
5. **Stuck for more than 15 minutes?** Google it. Then ask ChatGPT or Claude. That's what pros do too.

## How to Run Your Code

Open your terminal (Command Prompt on Windows, Terminal on Mac/Linux) and type:

```bash
python your_file_name.py
```

If that doesn't work, try:

```bash
python3 your_file_name.py
```
