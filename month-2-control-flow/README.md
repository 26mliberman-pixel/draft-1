# Month 2: Control Flow & Functions

Now your programs can make DECISIONS and REPEAT things. This is where it gets powerful.

## What You'll Learn

- **if/elif/else** — Make your program choose different paths
- **while loops** — Repeat something until a condition is met
- **for loops** — Repeat something a specific number of times
- **functions** — Reusable blocks of code
- **error handling** — Dealing with things that go wrong

## Key Concepts

- **Comparison operators**: ==, !=, <, >, <=, >=
- **Logical operators**: and, or, not
- **Booleans**: True and False
- **while loop**: Keeps going as long as a condition is True
- **for loop**: Goes through a sequence one item at a time
- **function**: A named block of code you can call whenever you need it
- **return**: How a function gives back a result
- **try/except**: Catching errors instead of crashing
